# WhisperTk

Interface gráfica simples para transcrição de áudio, vídeo e arquivos por URL utilizando Whisper.

## Recursos

- Seleção de arquivo de áudio ou vídeo
- Escolha do modelo Whisper
- Escolha do idioma
- Saída em TXT
- Interface gráfica em Tkinter
- Execução por arquivo BAT no Windows

## Requisitos

- Python 3.10 ou superior
- FFmpeg instalado
- OpenAI Whisper

## Instalação

pip install -r requirements.txt

## Executar

Dê dois cliques em:

abrir_whisper.bat

ou execute:

python whisper_gui.py
